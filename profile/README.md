# The Lunarian Foundation

## What is Lunarian and the purpose of this Org?

Lunarian is a beginner-friendly language made by Plentify under the Lunarian Foundation. The language's main purpose is to get people into coding and show you can do powerful stuff with the language without having a massive headache. The purpose of this org is to keep anything made with or for Lunarian stays under one umbrella.

## What is Lunarian written in?

Right now, as of 10/11/26 (MM/DD/YY) it is written in JavaScript and will hopefully be self-hosted by 2027.

## Why should I use Lunarian?

For new coders, transitioning to Lunarian is very easy and for veteran programmers, it has some things that could be recognizable.

## How can I use Lunarian?

Right now, Lunarian is in a semi-open beta, the interpreter is a VS Code plugin, and if you want to test it, you can contact us on discord (@plentify_).
